# Local Workstation Prerequisites

To build, containerize, and test this project locally, ensure the following tools are installed:

- **OS:** Windows 10/11 with WSL 2 enabled
- **Version Control:** Git (`git --version`)
- **Container Runtime:** Docker Desktop with WSL 2 backend (`docker --version`)

## Useful Docker Diagnostic Commands
- Check running containers: `docker ps`
- Check all containers (including exited): `docker ps -a`
- List local Docker images: `docker images`
